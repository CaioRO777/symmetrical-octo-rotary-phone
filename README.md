## 📖 Sobre o Projeto

Este projeto foi desenvolvido para consolidar os conhecimentos básicos de desenvolvimento Front-end (HTML, CSS e JavaScript). O objetivo principal foi criar uma aplicação útil que aplicasse conceitos de **lógica de programação** e **manipulação do DOM** em uma interface agradável e centralizada.

---

## ✨ Funcionalidades

- ✅ Inserção de 4 notas através de formulário numérico.
- ✅ Cálculo automático da média final.
- ✅ **Feedback visual dinâmico:** O texto muda para 🟢 Verde (Aprovado) ou 🔴 Vermelho (Reprovado).
- ✅ **Prevenção de erros (UX):** Após o cálculo, os campos de nota são bloqueados para edição e o botão principal se transforma num botão de "Limpar", permitindo iniciar um novo cálculo sem precisar recarregar a página.

---

## 🧠 O que aprendi

Durante a construção deste projeto, foquei em praticar:

* **Estilização e Layouts:** Utilização de `Flexbox` para centralizar elementos horizontal e verticalmente na tela.
* **Manipulação de DOM:** Como resgatar valores de inputs (`.value`) dinamicamente com JavaScript.
* **Lógica de Programação:** Uso de laços de repetição (`for`) para somar itens de um *Array* e estruturas condicionais (`if/else`) para definir a aprovação.
* **Interatividade Avançada:** Aprender a alterar o estado dos elementos dinamicamente (adicionando `.disabled` nos inputs) e redefinir o estado da aplicação através do botão de reset.
